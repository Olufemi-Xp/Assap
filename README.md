# ASAP - Local Service Providers Across Nigeria

> Fast, mobile-first Progressive Web App (PWA) connecting verified local artisans (plumbers, electricians, cleaners, carpenters, and mechanics) with nearby customers across all 36 states of Nigeria.

## Features
- **PWA Ready**: Offline shell caching, installable on mobile devices.
- **Zero-Cost Identity Records**: Live camera selfie + valid ID upload (NIN, Voter's Card, Driver's License, Passport).
- **Location Discovery**: All 36 states of Nigeria + FCT with star-rating ranking.
- **1-Month Free Trial**: Service providers receive an automatic 30-day active trial.
- **₦1,000/Month Paystack Billing**: Zero fixed platform fee, per-transaction Paystack checkout.
- **Zero Grace Period Enforcement**: Unpaid/expired provider phone and WhatsApp contacts are hidden immediately.
- **Star Ratings & Safety**: 1–5 star reviews, customer reports, and user-to-user blocking.

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run unit, integration, and E2E simulation tests
npm test

# Run strict TypeScript verification
npm run typecheck

# Build production bundle
npm run build
```

## Environment Variables
Copy `.env.example` to `.env.local` and configure your Supabase, Paystack, and OpenRouter keys.
